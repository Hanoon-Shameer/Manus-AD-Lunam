### PROJECT: MANUS AD LUNAM

### Project Overview: The M.A.L. BOT
The M.A.L. BOT is an AI-powered lunar rover designed to navigate rough, rigid terrain. Instead of using a traditional joystick, the rover is controlled via AI-driven hand gestures. It is built to traverse obstacles and seamlessly transmit data back and forth with a specialized control center.

**Exhibition Space**
Location: A dedicated project room generously provided by the IT Club.

Goal: The exhibition must be highly functional and visually appealing, maximizing the use of the assigned space within the given time frame.
